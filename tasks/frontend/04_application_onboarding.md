# Frontend Task 04 — Register an Authorised Lovable App

## Goal

Let the demo user register one Lovable app they are authorised to test.

## Implementation

- Build application list, empty state, and small add/edit/archive flow.
- Collect name, authorised public base URL, environment, and a testing-authorisation attestation.
- Explain that scans are bounded and cannot prove all business logic correct.
- Validate input accessibly, while treating backend validation as authoritative.

## Local acceptance criteria

- A user can add and manage a Lovable-app record through the local backend.
- Invalid URL and missing attestation display useful errors.

## Mandatory cross-check before Frontend Task 05

Create, edit, and archive a disposable record; simulate API failure; and verify the attestation is clear and persisted. Do not begin Task 05 until all checks pass.
