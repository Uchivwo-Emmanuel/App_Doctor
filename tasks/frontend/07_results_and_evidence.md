# Frontend Task 07 — Scan Results and Evidence

## Goal

Make the scan results useful enough to discuss a real Lovable issue tomorrow.

## Implementation

- Build run summary, result list, state filters, and result detail.
- Show assertion, plain-language result, timestamps, duration, scope, and limitations.
- Show private screenshot/artifact evidence through authorised backend links only; never raw paths or public storage URLs.
- Keep console/network technical detail redacted and collapsible.

## Local acceptance criteria

- Fixture failures and evidence are understandable and visible to the demo user.
- Failed/inconclusive results state what was observed and what was not established.

## Mandatory cross-check before Frontend Task 08

Review every fixture result state, artifact error state, and copy for unsupported “bug-free” or root-cause claims. Do not begin Task 08 until all checks pass.
