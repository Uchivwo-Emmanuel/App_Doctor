# Frontend Task 12 — Shared Visual Tokens

## Goal

Replace ad-hoc page colours with named App Doctor tokens shared by landing, workspace, forms, results, and diagnostics.

## Implementation

- Define semantic background, surface, text, border, teal accent, and status tokens.
- Apply them to every existing frontend component without changing status meaning.
- Preserve text labels and focus treatment so colour is never the only signal.

## Mandatory cross-check before Frontend Task 13

Review public/workspace screens side by side in desktop and mobile widths. Confirm contrast, focus states, and visual hierarchy are consistent.
