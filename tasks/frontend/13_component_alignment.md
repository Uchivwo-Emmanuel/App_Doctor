# Frontend Task 13 — Component Alignment

## Goal

Align buttons, cards, fields, navigation, badges, empty states, and error states to the shared App Doctor system.

## Implementation

- Standardise radius, borders, shadows, spacing, icon treatment, and hover/focus behaviour.
- Remove one-off styles that conflict with the landing page’s composed visual language.
- Keep controls keyboard accessible and touch friendly.

## Mandatory cross-check before Frontend Task 14

Exercise all interactive controls and inspect each state: default, hover, focus, disabled, loading, error, and empty.
