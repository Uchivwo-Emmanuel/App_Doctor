# Frontend Task 02 — App Doctor Dashboard Shell

## Goal

Build the calm, original App Doctor dashboard shell needed for tomorrow—not a generic AI landing page or a ChatGPT clone.

## Implementation

- Define accessible tokens for colour, type, spacing, radius, shadows, status, and focus.
- Add reusable Button, Input, Textarea, Card, Badge, Dialog/Sheet, table, and loading/empty/error components.
- Build desktop/mobile navigation for Dashboard, Applications, Runs, and Issues.
- Include textual status labels alongside colour/icon and respect keyboard/reduced-motion needs.

## Local acceptance criteria

- Desktop and mobile layouts have no horizontal overflow.
- Navigation and focus are usable without a mouse.

## Mandatory cross-check before Frontend Task 03

Manually test desktop/mobile layouts, keyboard traversal, landmarks, and component reuse. Do not begin Task 03 until all checks pass.
